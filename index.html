Direct charges

  • Charge created on the seller's account
  • Seller pays Stripe fee
  • Platform earns application_fee_amount
  • Disputes hit the seller first

Destination charges

  • Charge on the platform, transfer_data.destination
  • Platform pays Stripe fee
  • Seller receives gross minus fee
  • Disputes hit the platform

Separate charges & transfers

  • Platform charges once, transfers per seller
  • Linked by transfer_group / source_transaction
  • Only model that splits one cart
  • Platform pays Stripe fee and handles disputes

The real Stripe cost, not the fee field

Charge charge = Charge.retrieve(chargeId,
    ChargeRetrieveParams.builder()
        .addExpand("balance_transaction").build(),
    opts);

BalanceTransaction bt = charge.getBalanceTransactionObject();

// bt.getFee() = stripe_fee + application_fee on a direct charge.
// Storing it as "Stripe cost" double-counts your commission.
long stripeCost = bt.getFeeDetails().stream()
    .filter(f -> "stripe_fee".equals(f.getType()))
    .mapToLong(BalanceTransaction.FeeDetail::getAmount)
    .sum();

Connect webhook: raw body, verify, store, 200

@PostMapping("/webhooks/stripe/connect")
ResponseEntity<Void> connect(@RequestBody String payload,
        @RequestHeader("Stripe-Signature") String sig) {
    Event event;
    try {
        event = Webhook.constructEvent(payload, sig, connectSecret);
    } catch (SignatureVerificationException e) {
        return ResponseEntity.badRequest().build();
    }
    if (!inbox.insertIfAbsent(event.getId(), event.getAccount(),
                              event.getType(), payload)) {
        return ResponseEntity.ok().build();   // duplicate delivery
    }
    processor.enqueue(event.getId());           // async
    return ResponseEntity.ok().build();
}
